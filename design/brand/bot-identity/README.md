# Bot identity assets

- `faces/<id>.svg`: one face per file. Any face takes any palette colour: the head is the bot’s colour, the features are the theme’s ink, so face and colour are picked separately. Colour it with CSS custom properties on the element or a parent when the SVG is inlined: `--bot-face` (the fill), `--bot-ink` (the features) and `--bot-rim` (an optional 1.5-unit edge for deep fills on a dark page). Used as an `<img>`, a file shows its fallback colours (stone and ink).
- `faces/manifest.json`: the face ids (the config’s `avatar.preset` values: stable, never renamed), their names and expressions, and the identity palette in light and dark.
- `faces.js`: the source drawings, and `faceSVG(id, { fill, ink, rim, size })` to render one inline with explicit colours.
- `PALETTE.md`: the palette checks (generated by `tools/bot-palette.mjs`).

Regenerate the files after changing a face: `node tools/bot-faces.mjs`. The rules (where the colour goes, the fallback, voice presets) are in `BRAND.md › Bot identity` and in the brand book.
