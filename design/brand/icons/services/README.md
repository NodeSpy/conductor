# Service glyphs

Monochrome glyphs for the services a connection or runtime names (GitHub, PagerDuty, Terraform…), from
[Simple Icons](https://simpleicons.org) (CC0 1.0, see `LICENSE.md`). The marks are their owners’
trademarks and are used only to name the service, never as a status or decoration. Simple Icons
removes a brand when its owner objects, so some services have no glyph here (Slack, AWS, OpenAI):
the generic plug stands in, or the plugin ships the mark under that brand’s own guidelines.

Usage rules: BRAND.md › Fact types. Bundled into `icons/icons.js` (`SERVICES`) by `tools/icons.mjs`.
