Conductor

Connect to a conductor daemon. This app signs in with your SSH key and watches for things that need you, even while the window is closed.

The host must be exactly localhost (a daemon on this machine) or the daemon's Tailscale MagicDNS name (a remote one) — the daemon checks the Host header and will refuse anything else.

Defaults to the first of id_ed25519.pub, id_ecdsa.pub, id_rsa.pub found in ~/.ssh. The matching private key must be usable (directly or via ssh-agent) for both sign-in and the in-page "sign with SSH agent" step-up prompts.
